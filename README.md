# se-labs-0612371
## MCP servers

This repo includes a project-scoped MCP config (`.mcp.json`) for the
[Bland AI](https://bland.ai) MCP server at `https://api.bland.ai/v1/mcp`.

Set your Bland API key in the environment before starting Claude Code:

```bash
export BLAND_API_KEY="your-bland-api-key"
```

The key is read from the environment at startup and is never committed.
